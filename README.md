# 🍽️ Restaurant Order Analysis Using SQL

## 📌 Project Overview
This project analyzes restaurant orders, customer behavior, and restaurant performance using SQL. The goal is to extract meaningful business insights and answer practical questions using SQL queries.

## 🎯 Objectives
- Analyze total orders and customer spending.
- Identify top-spending customers.
- Calculate average order amounts by city.
- Analyze popular payment methods.
- Calculate running revenue totals.
- Rank restaurants by revenue.
- Identify the second-highest order amount.

## 🗂️ Project Files
- `customers.csv` — Customer dataset
- `orders.csv` — Restaurant order dataset
- `restaurants.csv` — Restaurant dataset
- `Thirupathi_Restaurant_Order_Analysis_SQL...` — SQL analysis queries

## 🛠️ Tools & Skills
- SQL
- MySQL Workbench
- Joins and aggregate functions
- GROUP BY and HAVING
- CASE statements
- Common Table Expressions (CTEs)
- Window functions: RANK(), DENSE_RANK(), ROW_NUMBER()
- Running totals and business analysis

## 📊 Key Business Questions
1. How many orders does each customer place?
2. What is the average order amount by city?
3. Who are the top five customers by spending?
4. Which payment method is used most frequently?
5. What is the running total of revenue?
6. Which restaurants generate the highest revenue?
7. What is the second-highest order amount?

## 🚀 How to Use
1. Download the CSV files from this repository.
2. Import the datasets into MySQL Workbench.
3. Create or select the project database.
4. Execute the SQL queries in the provided script.
5. Review the results to understand customer and restaurant performance.
